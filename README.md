# Daily Expense Tracker 💸

A web-based application to track daily expenses with category-wise analytics.
Built using Vanilla JavaScript and browser localStorage.

## Features
- Add, edit, delete expenses
- Category-wise summaries
- Monthly filtering
- Analytics dashboard
- Offline support (localStorage)
- Responsive UI

## Tech Stack
- HTML
- CSS
- JavaScript

## How to Run
1. Clone the repository
2. Open `index.html` in a browser  

## Use Case
Designed for personal finance tracking web project.

## Usage
1. Click "Add Expense" to record a new expense.
2. Use category filters to view specific expenses.
3. Check the Analytics dashboard for monthly insights.
